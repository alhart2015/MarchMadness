## Verdict

**MARGINAL WINNER (different cell from PR 7): (W_UPSET=1.25, W_MISS=0.0)
at 2690 brkt pts (+20 vs v8).** Recommend candidate-only, not
swap-in. Profile is more robust than PR 7's winner: 4W-2L over 22
LOSO seasons, max single-season delta +8 (vs PR 7's +12 from a single

## Bug

`src/train_upset_model.py:299` (pre-fix):

```python
apply_df["round"] = 0.0  # unknown at apply time -- pairwise CSV has no DayNum
```

Training-time `round` came from played-game `DayNum` via
`day_to_round` (range 1..6). Apply-time was hardcoded to 0. Tree
splits learned on the round feature during training never fired at
inference.

## Fix

New helper `build_pair_round_lookup(season, slots_df, seeds_df)`:

- Filter `MNCAATourneySlots.csv` and `MNCAATourneySeeds.csv` to season.
- Walk slots in ascending round order; for each slot, recursively
  expand `StrongSeed` and `WeakSeed` references into the set of leaf
  seed strings reachable through that slot.
- For every pair of leaves in a slot's reachable set, record the
  slot's round as the round at which those seeds would meet -- but
  only if no smaller round has been recorded for that pair.
- Resolve seed strings to team IDs via `seeds_df`; canonicalize each
  pair as `(min, max)`.

`build_v9_pairwise` now takes `slots_csv` (path) as a required
argument. Its apply path replaces the hardcoded
`apply_df["round"] = 0.0` with a per-pair lookup against the helper.
The sweep driver `run_single_cell` / `run_sweep` / `main` thread the
slots path through.

26 unit tests in `tests/test_upset_model.py` and 7 driver tests in
`tests/test_sweep_v9_weights.py` cover: helper behavior on real 2024
data (R1, R2, R4 same-region; R5/R6 cross-region; ~2016-pair
coverage; canonical pair ordering) and round non-zero at apply for a
canonical W01-vs-W16 R1 pair.

## Round-fix impact summary

The round fix's per-cell impact is non-uniform:

- Bottom-left of the grid (low weights -- the productively-useful
  region): modest changes. Anchor +4, (1.0, 0.5) unchanged, (1.25,
  0.0) +20.
- High-W_UPSET cells: large positive deltas (+57, +119, +68) but
  starting from way below v8 -- still below v8 even after the
  gains. Round signal was being washed out by aggressive weighting,
  not by the round=0 hardcoding alone.
- Net effect: the fix promotes (1.25, 0.0) over (1.0, 0.5) as the
  best cell, and improves the anchor's calibration slightly. Worth
  fixing on those grounds even when the headline winner-delta only
  moves from PR 7's +18 to +20.

## Recommendation

**Candidate-only, not swap-in.** Reasons:

- +20 vs v8 falls in the spec's "marginal" band (10 < d <= 25).
  Within this band, the spec calls for documentation, not auto-swap.
- More robust profile than PR 7's winner: 4W-2L spread, max single-
  season delta +8 (vs PR 7's +12 from 2024 alone). The win is less
  fragile.
- Mechanism is now interpretable as "v8's stage-2 plus mild upset
  weighting" -- the original v9 hypothesis ("upset weighting helps")
  is now partially supported, which it was not after PR 7 (PR 7's
  winner was W_MISS-only).
- v9-B's structural quirks unaddressed: 7 features still include
  `v4_confidence` and `is_a_higher_seed` which the model may or may
  not be using productively. A v9-A (4-feature) variant -- not in
  the merged code -- could be a cleaner test.

For a swap-in to make sense, we would want either (a) +25 or more
vs v8, or (b) better F4/E8 accuracy specifically, since that is
where bracket points come from. Neither is here.

## Caveats

- **Anchor sanity gate exceeded.** The driver printed
  `WARNING: anchor cell does not reproduce v8 within 5 pts; sweep
  is invalid -- something material has changed since the v9
  findings.` The "material change" is the round fix itself.
  Per-game LL/Acc still match v8 to 3 decimals, so the trainer is
  not broken; the fix just legitimately moves apply-time predictions
  by a small amount. Future re-runs against this same trainer
  should not re-trigger this warning unless something else changes.
- **Multiple-comparisons bias still applies.** Best of 15 cells. The
  +10 bar was set conservatively for this; +20 clears it but is not
  overwhelming.
- **W_UPSET=1.25, W_MISS=0.0 vs PR 7's W_UPSET=1.0, W_MISS=0.5.** A
  re-run of PR 7's identical grid produced two different winners
  with similar magnitudes (+20, +18). This sensitivity to the
  apply-time round value is itself a data point: the v9-B model is
  near the edge of detecting a real signal.
